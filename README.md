# Food Shop Website

A small food-shop demo website built with HTML, CSS, JavaScript and Bootstrap.

**Built by Tasleem Bibi** — BSCS student, Begum Nusrat Bhutto Women University, Sukkur, Pakistan.

## Features

- Home, About, Menu and Contact sections with a Bootstrap navbar
- Menu cards with food photos, descriptions and prices in PKR
  - Pizza — Rs. 100, Burger — Rs. 80, Pasta — Rs. 150, Biryani — Rs. 120, Juice — Rs. 50, Cold Drinks — Rs. 30
- "Order Now" button: type a food name and see its price in a prompt/alert
- Contact form with basic JavaScript validation (name, email and message are required)
- Custom styling in `style.css` on top of Bootstrap

## How to run

No build step and no server needed:

1. Download / clone this repository.
2. Open `index.html` in any browser (double-click it).

Bootstrap is loaded from a CDN, so an internet connection is needed for the Bootstrap styling.
